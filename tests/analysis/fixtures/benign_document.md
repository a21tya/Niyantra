# Developer Onboarding Guide

Welcome to the AEGIS project repository!

### Getting Started
1. Clone the repository using HTTPS or SSH.
2. Review our official documentation at [AEGIS Docs](https://docs.aegis-security.internal/guide).
3. Run tests using `npm test`.

### Safe Coding Guidelines
- All secrets must be provided via environment variables.
- Review and sanitize all user input before passing it to internal services.
